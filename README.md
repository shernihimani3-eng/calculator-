# 🧮 Simple Calculator

This is a basic calculator web application built using HTML, CSS, and JavaScript.

## 🚀 Features
- Addition
- Subtraction
- Multiplication
- Division
- Clear button
- Delete last character
- Error handling

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript

## 📌 How to Use
1. Enter numbers using the buttons.
2. Choose an operator (+, -, *, /).
3. Press "=" to get the result.
4. Press "C" to clear.

## 📷 Project Preview
Open index.html in your browser to run the project.
